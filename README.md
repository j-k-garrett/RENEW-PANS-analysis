# RENEW-PANS-analysis
R code for secondary analysis of the People and Nature Survey, exploring relationships between land cover, perceived quality and well-being

This repo contains two R Markdown scripts
1. 1_pans_data_descriptives
This prepares the data and constructs the sample descriptive tables

Set the directory where your data is located in line 39, with the variable "data_d"

2. 2_pans_modelling

This carries out the analysis and prepares results tables and plots
